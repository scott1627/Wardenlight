Wardenlight - Technic Platform Package
==========================================
Minecraft Version: 1.19.2
Forge Version: 43.5.2 (located in bin/modpack.jar)

HOW TO CREATE AND UPLOAD TO TECHNIC:
1. To build the upload ZIP:
   Select all files and folders INSIDE this directory (bin, mods, config, etc.)
   and compress them into a .zip file (e.g., Wardenlight-v1.5.0.zip).
   IMPORTANT: Do NOT zip the outer folder itself; the 'bin' and 'mods' folders MUST be at the root of the ZIP!

2. Host the ZIP:
   Upload the ZIP to a direct-download file host (e.g. GitHub Releases, Cloudflare R2, AWS S3, or your own web server).
   If using Dropbox, change ?dl=0 to ?dl=1 at the end of the URL.

3. Technic Platform Settings:
   - Go to https://www.technicpack.net/modpack/create
   - Modpack Location: Direct download URL to your hosted ZIP
   - Minecraft Version: 1.19.2
   - Java: Instruct players to use 64-bit Java 17 and allocate at least 8 GB - 12 GB RAM.
